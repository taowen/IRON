# Q4NX Generated MIR VUPS Advance Gate

This experiment makes a small schedule-changing MIR variant in the MyLM Q4NX
hot loop.

It moves the `vups.4x` at `0x704` one bundle earlier to `0x700`, and moves the
original `bmhh1` high-half copy into the `0x704` bundle with the dependent
`vadd`.

The intent is to test a performance-relevant scheduling move without changing
the full hot-loop harness:

- generate the whole `0x260..0x1850` hot loop from pre-bundled MIR;
- patch the generated bytes into the raw MyLM main16 program;
- compare NPU output against the unmodified MyLM raw program;
- require both direct-QKV and asymmetric-zero gates before using this style in
  a larger generated block.
